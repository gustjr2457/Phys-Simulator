## 기초 과정 — 초급 과정 (11종)

공식을 하나도 몰라도 볼 수 있는, 가장 먼저 보는 중분류입니다. 계산이 아니라 "감"을 잡는 것이 목표입니다. 여기의 모든 시뮬레이션에는 **도전 과제**(아래 별도 절 참고)가 붙어 있습니다.

**거시세계**
1. **에너지란 무엇인가?** — 튀는 공. 형태(높이의 에너지 ↔ 빠르기의 에너지 ↔ 소리·열)만 바뀌고 총량은 절대 변하지 않음을 막대로 확인
2. **힘이란 무엇인가?** — 크기와 방향을 가진 화살표(벡터) 두 개를 동시에 걸어 벡터 합(알짜힘)이 실제 운동을 결정한다는 것, 알짜힘이 0이면(힘의 평형) 물체가 움직이지 않는다는 것을 확인
3. **파동이란 무엇인가?** — 횡파/종파 비교. "파동은 흔들림을 전달할 뿐, 매질 입자는 제자리에서만 움직인다"는 것을 강조
4. **열이란 무엇인가?** — 뜨거운 블록과 차가운 블록을 붙였을 때, 열은 항상 뜨거운 쪽 → 차가운 쪽으로만 흐르고 결국 같은 온도(열평형)에서 멈춘다는 것을 계산 없이 확인
5. **엔트로피란 무엇인가?** — 칸막이를 치우면 입자들이 저절로 상자 전체로 퍼지지만, 저절로 다시 한쪽에 모이는 일은 없다는 것을 눈으로 확인. "왜 열은 거꾸로 흐르지 않는가"에 대한 진짜 답(경우의 수)의 예고편
6. **중력과 시간 — 왜 시간은 다르게 흐르는가?** — 지구에 남은 사람 / 빛의 속력에 가깝게 나는 로켓 / 중력이 아주 강한 곳(중성자별·블랙홀 근처)에 머무른 사람, 세 개의 시계를 나란히 비교. "빠르게 움직이면 시간이 느려진다"(특수 상대성 `√(1−β²)`)와 "중력이 강하면 시간이 느려진다"(일반 상대성 `√(1−x)`, x=r_s/r)가 원인이 다른 별개의 효과라는 것, 그리고 "로켓을 타고 우주로 멀리 나가는 것" 자체는 (중력이 오히려 약해지므로) 시간을 거의 바꾸지 않는다는 흔한 오해도 함께 짚어 줌. 두 식 모두 근사가 아닌 정확한 식
7. **중력이란 무엇인가?** — 같은 궤도 운동 하나를 뉴턴("끌어당기는 힘", F=GMm/r²)과 아인슈타인("휘어진 시공간을 따라 굴러갈 뿐", 고무판 비유의 격자 왜곡)으로 나란히 비교. 태양계처럼 중력이 약한 곳에서는 두 설명이 실제로 같은 답을 준다는 것, 그리고 슈바르츠실트 반지름(r_s)이 두 이론이 갈라지는 기준이라는 것까지 연결
8. **블랙홀과 중성자별이란 무엇인가?** — 같은 질량을 점점 더 작게 압축하는 하나의 실험으로 통일. 반지름을 줄일수록(로그 스케일 슬라이더) 밀도와 탈출 속도가 치솟다가, 탈출 속도가 빛의 속력에 도달하는 순간(r_s=2GM/c²) 블랙홀이 됨. 이 식이 아인슈타인보다 150년 앞서 존 미첼(1783)이 순수 뉴턴 역학으로 유도했다는 역사적 사실도 소개

**미시세계**
9. **입자란 무엇인가?** — 물질은 끊임없이 움직이는 작은 알갱이의 모임이라는 것. 온도 슬라이더 하나로 고체 → 액체 → 기체 상태 변화를 눈으로 확인(운동론적 분자 모델의 단순화)
10. **원자란 무엇인가?** — 입자(알갱이) 자체도 원자핵(양성자+중성자)과 그 둘레를 도는 전자로 되어 있다는 것. 양성자 수 하나로 원소가 정해짐(단순화된 보어 모형)
11. **빛이란 무엇인가?** — 빛의 파동성과 입자성(광자)을 한 화면에서 동시에 제시. 파장이 색을 정하고, 파장이 짧을수록 광자 하나의 에너지가 큼

## 문제방 — 도전 과제(Challenge) 기능

"이런 상황을 만들려면 값을 어떻게 조작해야 할까?"를 직접 실험하며 알아내는 미니 게임입니다. 정답을 입력하는 퀴즈가 아니라, **슬라이더를 움직이면서 목표 상태에 도달했는지를 실시간으로 확인**하는 방식입니다.

무대(캔버스) 바로 아래에 **"🎯 문제방"** 이라는 이름의, 다른 카드들과 뚜렷이 구분되는 독립된 영역으로 표시됩니다 — 공식·슬라이더·측정값 카드들과 섞이지 않도록 일부러 분리했습니다(처음엔 우측 패널 안에 다른 카드처럼 넣었다가, 눈에 잘 안 띈다는 피드백을 받고 무대 아래 별도 구역으로 옮겼습니다).

- 시뮬레이션 정의에 `challenges: [{ id, title, desc, check(ctx), hint }]`를 추가하면 문제방이 자동으로 생깁니다(없는 시뮬레이션에서는 문제방 자체가 숨겨짐).
- `check(ctx)`는 매 프레임 `{ P: 현재 슬라이더 값, st: 현재 시뮬레이션 상태, t: 경과 시간 }`을 받아 `true/false`를 반환하는 순수 함수입니다 — 슬라이더 값만 보는 것(예: "알짜힘을 0으로")도, 재생하며 지켜봐야 하는 것(예: "6초가 지나도 계속 튀게")도 모두 표현할 수 있습니다.
- 목표를 만족하는 동안은 ✅, 한 번이라도 만족한 적이 있으면(슬라이더를 다시 바꿔도) ✔로 계속 남아 성취를 기억합니다(새로고침하면 초기화).
- 힌트는 기본적으로 접혀 있어 스스로 먼저 찾아보게 하고, 필요하면 "힌트 보기"로 펼칠 수 있습니다.
- 현재 **13개 시뮬레이션**(초급 · 개념 11종 전체 + 일반물리의 "특수 상대성이론" + 유명한 실험의 "은하 회전 곡선과 암흑물질")에 2개씩, 총 **26개**의 도전 과제가 있습니다. 각 도전 과제는 실제로 그 조작으로 달성 가능한지, 그리고 시뮬레이션을 열자마자(아무 조작도 없이) 트리비얼하게 달성되어 버리지는 않는지를 `scratchpad/check_challenges.js`로 전수 검증했습니다 — 검증 중 실제로 여러 설계 버그(허용 범위 안에서 절대 달성 불가능한 문턱값, 기본값 자체가 이미 정답이라 조작이 필요 없던 챌린지, 목표 지점의 문턱값 계산 실수)를 발견해 고쳤습니다.

## 기초 과정 — 고등물리 · 물리학Ⅰ (7종)

**역학과 에너지**
1. **등가속도 직선 운동** `v = v₀ + at`, `s = v₀t + ½at²` — 1초 간격 스트로보 잔상, v–t / s–t 그래프, `v² − v₀² = 2as` 실시간 검산
2. **뉴턴 운동 제2법칙** `F = ma` — 힘·마찰력·수직항력·무게 화살표, 알짜힘 막대, 정지 마찰 판정
3. **운동량과 충격량** `p = mv`, `I = FΔt = Δp` — 반발계수 e로 탄성/비탄성 충돌, 운동량 보존 그래프, 충돌 시간에 따른 평균 힘(에어백 원리)
4. **역학적 에너지 보존** `E = ½mv² + mgh` — 롤러코스터, K/U 스택 막대, 마찰에 의한 에너지 손실

**물질과 전자기장**

5. **전자기 유도** `V = −N ΔΦ/Δt` — 자석 왕복, 자기 선속 화살표 밀도, 검류계 바늘, 유도 전류 애니메이션, 렌츠 법칙 안내

**파동과 정보통신**

6. **파동의 표현** `v = fλ` — 매질 입자는 제자리 진동(빨간 점)임을 강조, 파장·진폭 치수선, 마루 추적 표식, y–t 그래프
7. **빛의 굴절과 전반사** `n₁sinθ₁ = n₂sinθ₂` — 매질 경계에서 꺾이는 빛, 임계각을 넘으면 100% 반사되는 전반사, 광섬유(광통신)·다이아몬드가 반짝이는 이유

## 기초 과정 — 일반물리 (6종)

**회전운동**
1. **회전운동과 각운동량** `L = Iω` — 팔을 오므리는 피겨스케이팅 선수 비유, 각운동량 보존, 팔을 오므릴 때 회전 운동에너지는 오히려 늘어난다는 것(L 보존 ≠ 에너지 보존)까지 함께 확인

**진동과 파동**
2. **단진동(SHM)** `x(t) = A cos(ωt)` — 감쇠가 전혀 없는 이상적인 스프링-질량계. 기계공학 · 진동공학의 "감쇠 자유진동"의 감쇠기를 뗀 기초형. 진폭과 무관하게 진동수가 일정함, 에너지가 스프링 ↔ 운동 사이만 오간다는 것을 확인

**광학**
3. **렌즈와 상** `1/f = 1/u + 1/v` — 볼록렌즈(카메라의 실상, 돋보기의 허상)와 오목렌즈(근시 안경, 항상 축소된 허상)의 상 작도. 고등물리의 "빛의 굴절과 전반사"에서 이어짐

**열역학**
4. **열역학 제1법칙** `ΔU = Q − W` — 추의 무게로 압력을 일정하게 유지한 실린더를 가열하는 등압 과정. 들어간 열(Q)이 내부에너지 증가(ΔU)와 피스톤이 하는 일(W)로 나뉘고, 단원자 이상기체에서는 이 배분이 항상 정확히 3:2임을 해석해로 확인(수치오차 0)
5. **통계적 엔트로피** `S = ln Ω` — 에렌페스트 항아리 모형(입자가 무작위로 두 칸을 오감). 초급의 "엔트로피란 무엇인가?"에서 눈으로만 본 것을 실제로 세어서(Ω = C(N,k)) S=ln Ω로 계산. 입자 수(N)가 커질수록 요동이 작아짐을 통해 "열역학 제2법칙은 통계적 법칙"이라는 것을 확인

**상대성이론**
6. **특수 상대성이론** `γ = 1/√(1−β²)` — 초급의 "중력과 시간"에서 계산 없이 본 속도 효과를 정량적으로 확장. 로런츠 인자·시간 지연·길이 수축을 β 슬라이더 하나로 함께 확인하고, 운동에너지가 β→1에서 발산해서(γ−1→∞) 질량이 있는 것은 빛의 속력에 도달할 수 없다는 것까지 보여줌

앞으로 전자기학 확장(전기장·전위, 맥스웰 방정식 직관), 유체역학, 단진자 등을 계속 채워 나갈 예정입니다.

## 실험과 현대물리 — 유명한 실험 (4종)

초급·고등물리·일반물리에서 배운 이론이 "그래서 실제로 어떻게 증명됐는가"를 역사적 실험을 재현해서 보여줍니다. 계산이 목적이 아니라, 이론과 실제 데이터가 만나는 순간 자체를 체험하는 것이 목적입니다.

**빛의 정체를 밝히다**
1. **영의 이중슬릿 실험 (1801)** `d sinθ = mλ` — 광자를 하나씩(광원을 극도로 어둡게) 쏘아도 결국 같은 간섭무늬가 쌓인다는 것을 점이 누적되는 과정으로 직접 보여줌. 슬릿 1개(회절만, 매끈한 무늬) ↔ 슬릿 2개(간섭, 뚜렷한 줄무늬) 비교. 회절 포락선(sinc²) × 간섭(cos²)까지 반영한 실제 사진과 같은 모양
2. **광전효과 (1905)** `KE_max = hf − φ` — 빛이 파동이기만 하다면 설명 안 되는 현상: 진동수가 문턱보다 낮으면 아무리 밝혀도 전자가 0개, 문턱을 넘으면 즉시 튀어나옴. 빛의 밝기는 전자의 "개수"만, 색(진동수)만이 전자의 "속도"를 정한다는 것을 분리해서 확인. 아인슈타인이 노벨상을 받은 바로 그 실험

**물질의 구조를 밝히다**
3. **러더퍼드의 금박 산란 실험 (1911)** `tan(θ/2) = kZze²/(2Eb)` — 알파 입자를 금박에 쏘면 거의 다 통과하지만 아주 가끔 거의 정반대로 튕겨 나온다는 것 → 원자의 (+)전하와 질량 대부분이 아주 작은 한 점(원자핵)에 몰려 있다는 결론. 조준 거리(b)와 산란각의 관계는 뉴턴 역학 + 쿨롱 반발력만으로 유도되는 정확한 해석해. 표적 원자번호(Z)를 낮추면(금→알루미늄) 후방산란이 실제로 줄어드는 것까지 확인 가능

**우주의 구조를 밝히다**
4. **은하 회전 곡선과 암흑물질 (베라 루빈, 1970년대)** `v(r) = √(v_vis(r)² + v_dark²)` — 은하의 별 분포(허른퀴스트 질량 분포)만으로 예측한 회전 속도는 중심에서 멀어질수록 케플러 법칙대로 떨어져야 하는데, 실제 관측된 회전 곡선은 바깥쪽에서도 평평하게 유지됨. 이 차이를 메우려면 눈에 보이지 않는 질량 — 등온구 모델의 암흑물질 헤일로(회전 속도 기여가 반지름에 관계없이 정확히 일정) — 이 은하 전체를 감싸고 있어야 한다는 결론. 베라 루빈과 켄트 포드가 1970년대에 여러 은하에서 이 평평한 회전 곡선을 실측하면서 암흑물질의 존재를 뒷받침하는 핵심 증거가 됨

앞으로 마이컬슨-몰리 실험(빛의 속력 일정), 캐번디시 실험(중력상수 측정), 밀리컨 기름방울 실험(전하의 양자화), 슈테른-게를라흐 실험(스핀의 양자화) 등을 계속 채워 나갈 예정입니다.

## 실험과 현대물리 — 양자역학 (6종)

이 중분류는 **"입자도 파동처럼 군다"** 한 문장에서 전부 따라 나오도록 구성했습니다. 양자역학을 "이상한 것"으로 소개하지 않고, *파동이면 당연한 것*과 *정말로 새로운 것*을 분리해서 보여 줍니다.

| | 파동이면 당연한 것 | 정말로 새로운 것 |
|---|---|---|
| 에너지가 띄엄띄엄 | 기타 줄에 정수 배 반파장만 들어감 | |
| 위치·운동량을 동시에 모름 | 짧은 북소리에 여러 음이 섞임 | |
| 벽을 통과함 | 파동이 벽 안에서 지수적으로 감쇠 | |
| 간섭무늬 | 파동은 더해짐 | |
| 측정 | | **낱개로, 무작위 위치에, \|ψ\|²의 확률로 도착** |

**물질파**
1. **드브로이 파장** `λ = h/mv` — 전자·중성자·원자·바이러스·먼지·야구공을 로그 자 위에 놓고 파장과 물체 크기를 비교. 야구공의 10⁻³⁴ m를 직접 보여 "일상에서 양자가 안 보이는 이유"부터 해결

**양자화**

2. **상자 속 전자** `Eₙ = n²h²/8mL²` — 정상파 + |ψ|² + 에너지 사다리. δ 슬라이더로 정수가 아닌 양자수가 왜 금지되는지 직접 확인

**파동이면 당연한 것**

3. **불확정성 원리** `Δx·Δp ≥ ħ/2` — 위치 공간의 파속과 운동량 공간의 스펙트럼을 나란히. 가우시안으로 섞으면 정확히 ħ/2에서 등호가 성립하는 것을 측정값으로 확인
4. **터널링** `T ≈ e^(−2κd)` — 벽 안에서 지수적으로 줄어드는 파동과 반대편에 남는 꼬리. E > V₀에서도 되튕기는 공명 투과까지. STM·플래시 메모리·태양의 핵융합과 연결

**원자와 빛**

5. **에너지 준위와 스펙트럼** `Eₙ = −13.6Z²/n²` — 전이를 고르면 그 색의 광자가 날아가고 가시광선 띠에 선이 그어짐. 원 둘레의 정상파(2πr = nλ)로 2번과 연결

**측정이라는 것**

6. **관측하면 달라진다** — 전자를 하나씩 쏘아 점으로 쌓되, **경로 관측 비율**을 0→100 %로 올리면 무늬가 그 비율만큼 흐려짐(V ≈ 1 − f). "전자가 두 틈을 동시에 지난다"고 서술하지 않고, **묻지 않으면 줄무늬 / 물으면 두 덩어리**라는 관측 결과로만 기술

> 시각화 원칙: ① 확률은 반드시 점을 하나씩 쌓아서 보여준다 ② 전자를 핵 주위를 도는 공으로 그리지 않는다 ③ 단위는 nm와 eV로 쓴다
> 다루지 않는 것: 슈뢰딩거의 고양이·다세계 해석(측정 가능한 예측 차이가 없는 해석 논쟁), 스핀을 자전으로 그리기(틀린 그림)

## 응용 분야 — 항공우주공학 (5종)

고등물리의 *등가속도 운동·운동량*에서 이어집니다.

**비행역학**
0. **양력과 실속** `L = ½ρV²S·C_L` — 익형 주위 흐름선(순환 + 벽면 추종 변위), 받음각 조작, 박리점·재순환 와류·로그 나선 말림, C_L–α 곡선과 실속 영역

**궤도역학**
1. **인공위성의 궤도** `v² = μ(2/r − 1/a)` — 2체 문제 수치적분, 원↔타원↔탈출 전이, **케플러 제2법칙 등면적 부채꼴** 시각화
2. **호만 전이 궤도** `Δv₁ + Δv₂` — 2회 점화 자동 시퀀스, Δv 예산 막대, LEO→GEO 3,857 m/s 재현

**추진과 로켓**
3. **로켓 방정식과 궤도 진입** `Δv = Isp·g₀·ln(m₀/m_f)` — 중심력 2체 문제 + 피치 프로그램(중력 선회). 수직 발사로는 궤도에 오를 수 없음을 직접 확인, 중력 손실 적분, 근지점 고도로 궤도 판정
4. **다단 로켓과 단 분리** `Δv = Σ Isp·g₀·ln(m₀/m_f)` — 1~3단 비교(같은 총질량 300 t에서 1단 6,002 → 2단 9,944 → 3단 10,831 m/s), 단 분리와 낙하하는 빈 단, 단별 Δv 막대, 탑재체 질량 패널티

## 응용 분야 — 선박공학 (3종)

고등물리의 *부력·힘의 평형*에서 이어집니다. 자율운항시스템공학을 포함합니다.

**저항과 추진**
1. **선체 저항과 프루드 수** `Fn = V/√(gL)` — 정지에서 가속하며 마찰저항(ITTC-57)과 조파저항을 분리 기록. 배가 만드는 파도 λ = 2πV²/g가 선체 길이와 겹칠 때 생기는 험프, 경제 속력대(Fn ≤ 0.22) 표시
    *조파저항은 험프의 위치·크기를 보여주기 위한 교육용 근사식입니다(실제 설계는 수조시험·CFD).*

**복원성**
2. **선박의 복원성 (GM)** `GM = KB + BM − KG` — 횡요 동역학, 부심 B·무게중심 G·메타센터 M, GZ 곡선, GM<0 전복 재현

**운항 제어**
3. **자율운항 침로 제어** `δ = Kp·e + Ki∫e + Kd·r` — 노모토 조종 모델 + PID, 타각 포화(±35°), 외란과 정상상태 오차

## 응용 분야 — 기계공학 (6종)

항공우주공학·선박공학에 공통으로 필요한 기반 역학을 모은 중분류입니다.

**고체역학**
1. **응력-변형 선도** `σ = Eε` — 인장시험 재현. 훅의 법칙이 **항복점까지만** 참이라는 것, 탄성→소성→네킹→파단, "지금 당김을 풀면 돌아오는가"를 실시간 판정
2. **보의 굽힘과 처짐** `δ = PL³/3EI` — 외팔보의 정확한 3차 처짐 곡선, 인장/압축 표면 응력 색띠와 중립축, 단면 높이를 ½·2배로 했을 때의 유령선(8배 / ⅛)을 겹쳐 표시

**파괴역학**
3. **균열과 응력확대계수** `K_I = σ√(πa)` — 항복강도를 한참 밑도는 응력에서도 부서지는 이유. 균열 끝 응력 집중 흐름선과 소성역, K–a 선도 위의 임계 균열 길이 a_c, K ≥ K_IC에서 불안정 전파

**열공학**
4. **열전도와 열저항** `Q = ΔT/ΣR` — 열저항을 전기회로처럼 직렬로 그려 보여 줍니다. 층별 온도 강하가 저항 비중에 비례하는 온도 분포선, τ = RC로 식는 커피, "단열재를 더 두껍게 vs 바람을 막기" 중 어느 쪽이 병목인지 판정

**진동공학** — 고등물리의 *뉴턴 운동 법칙·에너지*에서 이어집니다
5. **감쇠 자유진동** `mẍ + cẋ + kx = 0` — 스프링·대시포트 애니메이션, 감쇠비 ζ 게이지(부족/임계/과감쇠), 지수 포락선 그래프
6. **강제 진동과 공진** `M = 1/√((1−r²)²+(2ζr)²)` — 주파수 응답 곡선 위의 작동점이 실시간 이동, 공진선(r=1)과 진동 절연 영역(r>√2) 표시

## 응용 분야 — 화학공학 (3종)

**반응공학**
1. **아레니우스 식** `k = A·e^(−Ea/RT)` — "온도 10도에 속도 2배"가 왜 성립하는지를 **분자 에너지 분포의 꼬리**(세로 로그 눈금)로 보여 줍니다. 문턱 Ea를 넘는 분자 비율 e^(−Ea/RT), 촉매가 하는 일, 1차 반응의 반감기가 농도와 무관함
2. **반응기 비교 — CSTR vs PFR** `τ = V/Q` — 같은 부피·같은 유량인데 전환율이 다른 이유. 관 안의 농도 구배 vs 탱크 안의 균일 희석, 담쾰러 수 kτ, "같은 성적을 CSTR로 내려면 부피 몇 배"
3. **관내 유동과 압력 손실** `Re = ρVD/μ` — 레이놀즈의 1883년 잉크 실 실험 재현. 유속을 스윕하며 층류→난류 전이 순간을 포착하고, 무디 선도(f–Re)와 Δp–Re를 직접 그립니다. 하겐-푸아죄유 + 하알란트 식

## 응용 분야 — 전기공학 (3종)

**회로이론**
1. **RC 회로의 과도응답** `τ = RC` — 사각파 전원으로 충·방전 반복. 1τ 상승 비율을 **실제로 측정**해 63.2%를 확인, 커패시터 판에 쌓이는 전하와 저항기 발열, τ/T 비에 따른 적분기(저역통과) 동작
2. **RLC 공진과 임피던스** `f₀ = 1/2π√(LC)` — 주파수 스윕으로 공진 곡선과 위상 곡선을 실험하듯 그립니다. 페이저로 V_L·V_C 상쇄를 보여 주고, 공진에서 V_L = Q·V가 되는 **전압 확대**까지 확인

**전력공학**
3. **변압기와 송전 손실** `P_loss = 3I²R` — 왜 765 kV로 보내는가. 발전소→승압→송전선→강압→도시 전 경로와 손실 아지랑이, 손실률–송전전압 곡선(1/V² 법칙) 위의 현재 작동점

## 응용 분야 — 공학응용 (2종)

분야를 가리지 않고 공통으로 쓰이는 계측·신호입니다. 고등물리의 *전자기 유도*에서 이어집니다.

**센서와 계측**
1. **스트레인 게이지와 브리지 회로** `Vo = Vs·GF·ε/4` — 외팔보 굽힘 + 게이지 신축, 휘트스톤 브리지, 증폭, 하중–출력 교정 곡선

**신호와 응답**
2. **센서의 응답 속도와 샘플링** `τẏ + y = u` — 63.2 % 시정수, 노이즈, ADC 샘플링 계단, 나이퀴스트

한 중분류에 등록된 시뮬레이션이 하나도 없으면 탭에 자동으로 "준비 중"으로 표시되고, 클릭해도 안전하게 안내 화면만 뜹니다(에러 없음).

좌측 목록은 `index.html`의 `<script>` 순서대로 쌓이므로, **같은 `category`(소분류)의 파일은 연달아 두어야** 소제목이 한 번만 나옵니다.

### 새 시뮬레이션 추가하기

`js/sims/<중분류 폴더>/새파일.js`를 만들고 `PS.register({...})` 후 `index.html`에 `<script>` 한 줄만 추가하면 목록에 자동 등록됩니다.

```js
PS.register({
  id, category, title, sub, tagline,
  mode: 'concept',                                                             // 'concept' | 생략(고등물리) | 'general' | 'exp' | 'quantum' | 'space' | 'adv'
  params:  [{ key,symbol,label,unit,min,max,step,value,color,reset, where }],  // where = "어디에서 작용하는가" 설명
  vars:    { 키: { symbol,label,unit,color,where } },                          // 슬라이더가 아닌 결과값 기호
  formulas:[{ name, tpl:'{v} = {v0} + {a}{t}' }],                              // {키} → 색이 있는 클릭 가능한 항 (괄호 안에 공백 금지)
  init(p), step(st,p,dt), draw(ctx,st,p,ui), readouts(st,p),
  graphs, sample, notes, presets,
  challenges: [{ id, title, desc, check(ctx), hint }]         // ctx = { P, st, t } — 선택 사항, 있으면 "도전 과제" 카드가 자동 생성됨
});
```

`mode`가 **중분류**(탭), `category`가 **소분류**(좌측 목록의 소제목)입니다. 대분류는 `js/app.js`의 `GROUPS` 배열이 `mode`들을 묶어 정의하므로, 새 중분류를 만들 때는 `GROUPS`·`TRACK_LABEL`·`index.html`의 `.mode` 버튼 세 곳을 함께 고치면 됩니다.

그래프는 기본이 시간축이며, `window: 8`을 주면 최근 8초만 흐르듯 보여 주고, `xKey: 'F'`를 주면 시간 대신 그 값을 가로축으로 씁니다(교정 곡선·특성 곡선용).

`draw()`의 `ui.hl`에 현재 강조 중인 기호 키가 들어옵니다. 이 값에 따라 해당 화살표/막대를 `hot: true`로 그리면 공식 ↔ 화면 연결이 완성됩니다.

## 다음 단계 후보

**기초 과정 — 초급 과정 (보강)**
- 소리란 무엇인가?(거시세계) — 파동이란 무엇인가?에서 이어지는 종파의 실제 사례
- 압력이란 무엇인가?(거시세계) — 입자란 무엇인가?·열이란 무엇인가?와 이어지는 기체 압력의 분자운동론적 그림

**도전 과제 확장**
- 현재는 초급 과정 · 양자역학 · 응용 분야에 붙어 있음 — 고등물리 → 일반물리 → 유명한 실험 순으로 나머지에도 확장 예정
- 여러 조건을 동시에 만족해야 하는 복합 도전 과제(예: "알짜힘은 0인데 두 힘의 크기는 다르게"는 불가능하지만, "운동량은 보존하면서 운동에너지는 최대한 잃게" 같은 트레이드오프형 과제)

**기초 과정 — 고등물리**
- 파동 단원 보강: 도플러 효과, 정상파
- 전자기 단원 보강: 전류에 의한 자기장, 전동기 원리

**기초 과정 — 일반물리 (다음 배치 후보)**
- 단진자(SHM의 또 다른 예), 전자기학(전기장·전위, 맥스웰 방정식 직관)
- 열역학 보강: 이상기체 상태방정식(PV=nRT), P-V 선도 위의 등온·단열 과정, 카르노 기관과 열효율
- 광학 보강: 거울(오목/볼록 거울의 상), 회절격자

**실험과 현대물리 — 유명한 실험 (다음 배치 후보)**
- 마이컬슨-몰리 실험(1887, 빛의 속력이 방향과 무관하게 일정함 — 상대성이론의 토대)
- 캐번디시 실험(1798, 비틀림 저울로 중력상수 G 측정 — 뉴턴 중력의 정량적 확인)
- 밀리컨 기름방울 실험(1909, 전하는 항상 e의 정수배로만 존재함을 측정)
- 갈릴레이의 낙하 실험(등가속도 운동의 역사적 기원), 푸코 진자(지구 자전의 직접 증명)
- 콤프턴 산란(광자도 운동량을 가진다는 것의 확인), 프랑크-헤르츠 실험(에너지 준위의 양자화)

**실험과 현대물리 — 양자역학 (보강 후보)**
- 슈테른-게를라흐 실험(스핀의 양자화 — 빔이 두 갈래로 갈라지는 관측 결과로만 서술)

- 얽힘과 벨 부등식(2입자 상관 통계 — 난이도가 높아 별도 검토 필요)
