# PhysLab — 물리 이론의 시각화 (프로토타입)

공식을 애니메이션으로 직접 조작해 보며 물리와 친해지는 웹 시뮬레이터입니다.
두 개의 트랙으로 나뉩니다.

| 트랙 | 대상 | 범위 |
|---|---|---|
| **기초 · 물리학Ⅰ** | 물리에 처음 흥미를 붙이는 단계 | 고등학교 물리학Ⅰ을 <b>넘지 않음</b> (기획서 원칙) |
| **심화 · 공학** | 전공에서 이 물리가 어떻게 쓰이는지 보고 싶을 때 | 학과별 대학 전공 기초 |

좌측 상단의 탭으로 전환합니다. 심화 트랙은 기초 트랙의 공식이 <b>실제 공학에서 어디로 이어지는지</b>를 보여주는 확장이며, 기초 트랙의 난이도 원칙에는 영향을 주지 않습니다.

## 실행 방법

의존성 없는 순수 HTML/CSS/JS입니다. 둘 중 아무거나:

```bash
node tools/dev-server.js
```
→ 브라우저에서 `http://localhost:5173`

또는 `index.html`을 브라우저로 그냥 열어도 됩니다.

## 기획 의도 → 구현 대응

| 기획서 항목 | 구현 |
|---|---|
| 공식의 용도에 맞는 체험 화면(애니메이션) | 시뮬레이션마다 전용 캔버스 애니메이션 + 실시간 그래프 |
| 공식 구성요소의 **위치** 구성 | 공식의 각 기호가 **고유 색**을 가지고, 기호에 마우스를 올리거나 클릭하면 ① 화면 속 해당 요소(화살표·막대·점선)가 빛나고 ② 해당 슬라이더가 강조되며 ③ "이 값이 어디에서 작용하는가" 설명이 뜹니다 |
| 값을 직접 대입해 보는 경험 | 모든 상수가 슬라이더 + 상황별 프리셋 버튼(달의 중력, 얼음판, 에어백 효과 등) |
| 물리학Ⅰ 범위 유지 | 미적분·벡터 성분 분해 없이, 교과서 공식과 용어만 사용 |

## 기초 트랙 — 물리학Ⅰ (6종)

**역학과 에너지**
1. **등가속도 직선 운동** `v = v₀ + at`, `s = v₀t + ½at²` — 1초 간격 스트로보 잔상, v–t / s–t 그래프, `v² − v₀² = 2as` 실시간 검산
2. **뉴턴 운동 제2법칙** `F = ma` — 힘·마찰력·수직항력·무게 화살표, 알짜힘 막대, 정지 마찰 판정
3. **운동량과 충격량** `p = mv`, `I = FΔt = Δp` — 반발계수 e로 탄성/비탄성 충돌, 운동량 보존 그래프, 충돌 시간에 따른 평균 힘(에어백 원리)
4. **역학적 에너지 보존** `E = ½mv² + mgh` — 롤러코스터, K/U 스택 막대, 마찰에 의한 에너지 손실

**물질과 전자기장**

5. **전자기 유도** `V = −N ΔΦ/Δt` — 자석 왕복, 자기 선속 화살표 밀도, 검류계 바늘, 유도 전류 애니메이션, 렌츠 법칙 안내

**파동과 정보통신**

6. **파동의 표현** `v = fλ` — 매질 입자는 제자리 진동(빨간 점)임을 강조, 파장·진폭 치수선, 마루 추적 표식, y–t 그래프

## 심화 트랙 — 공학 (11종)

**진동공학** — 기초의 *뉴턴 운동 법칙·에너지*에서 이어집니다
1. **감쇠 자유진동** `mẍ + cẋ + kx = 0` — 스프링·대시포트 애니메이션, 감쇠비 ζ 게이지(부족/임계/과감쇠), 지수 포락선 그래프
2. **강제 진동과 공진** `M = 1/√((1−r²)²+(2ζr)²)` — 주파수 응답 곡선 위의 작동점이 실시간 이동, 공진선(r=1)과 진동 절연 영역(r>√2) 표시

**센서공학** — 기초의 *전자기 유도*에서 이어집니다
3. **스트레인 게이지와 브리지 회로** `Vo = Vs·GF·ε/4` — 외팔보 굽힘 + 게이지 신축, 휘트스톤 브리지, 증폭, 하중–출력 교정 곡선
4. **센서의 응답 속도와 샘플링** `τẏ + y = u` — 63.2 % 시정수, 노이즈, ADC 샘플링 계단, 나이퀴스트

**항공우주공학** — 기초의 *등가속도 운동·운동량*에서 이어집니다
5. **양력과 실속** `L = ½ρV²S·C_L` — 익형 주위 흐름선, 받음각 조작, C_L–α 곡선과 실속 영역, 양력·무게 균형
6. **인공위성의 궤도** `v² = μ(2/r − 1/a)` — 2체 문제 수치적분, 원↔타원↔탈출 전이, **케플러 제2법칙 등면적 부채꼴** 시각화
7. **호만 전이 궤도** `Δv₁ + Δv₂` — 2회 점화 자동 시퀀스, Δv 예산 막대, LEO→GEO 3,857 m/s 재현
8. **로켓 방정식과 궤도 진입** `Δv = Isp·g₀·ln(m₀/m_f)` — 중심력 2체 문제 + 피치 프로그램(중력 선회). 수직 발사로는 궤도에 오를 수 없음을 직접 확인, 중력 손실 적분, 근지점 고도로 궤도 판정
9. **다단 로켓과 단 분리** `Δv = Σ Isp·g₀·ln(m₀/m_f)` — 1~3단 비교(같은 총질량 300 t에서 1단 6,002 → 2단 9,944 → 3단 10,831 m/s), 단 분리와 낙하하는 빈 단, 단별 Δv 막대, 탑재체 질량 패널티

**자율운항시스템공학(선박)** — 기초의 *부력·힘의 평형*에서 이어집니다

10. **선박의 복원성 (GM)** `GM = KB + BM − KG` — 횡요 동역학, 부심 B·무게중심 G·메타센터 M, GZ 곡선, GM<0 전복 재현
11. **자율운항 침로 제어** `δ = Kp·e + Ki∫e + Kd·r` — 노모토 조종 모델 + PID, 타각 포화(±35°), 외란과 정상상태 오차

## 조작

- `Space` 재생/일시정지 · `R` 처음으로
- 공식의 기호 클릭 = 고정 강조(다시 클릭하면 해제), 마우스 올리기 = 미리보기

## 코드 구조

```
Phys-Simulator/
├─ index.html          레이아웃(좌: 목록 / 중: 무대·그래프 / 우: 공식·값·측정값)
├─ vercel.json         정적 배포 설정 (빌드 과정 없음)
├─ tools/dev-server.js 로컬 미리보기 전용 (배포본에서는 제외)
├─ css/style.css
├─ js/core.js          시뮬레이션 등록기, 좌표 변환, 드로잉 헬퍼(화살표·치수선·막대·스프링·댐퍼), 미니 그래프
├─ js/app.js           UI 생성, 트랙 전환, 강조 연동, 고정 시간 간격(1/480 s) 애니메이션 루프
├─ js/sims/*.js        기초 트랙 (시뮬레이션 1개 = 파일 1개)
└─ js/sims/adv/*.js    심화 트랙
```

### 새 시뮬레이션 추가하기

`js/sims/새파일.js`를 만들고 `PS.register({...})` 후 `index.html`에 `<script>` 한 줄만 추가하면 목록에 자동 등록됩니다.

```js
PS.register({
  id, category, title, sub, tagline,
  mode: 'adv',                                                                 // 생략하면 기초 트랙
  params:  [{ key,symbol,label,unit,min,max,step,value,color,reset, where }],  // where = "어디에서 작용하는가" 설명
  vars:    { 키: { symbol,label,unit,color,where } },                          // 슬라이더가 아닌 결과값 기호
  formulas:[{ name, tpl:'{v} = {v0} + {a}{t}' }],                              // {키} → 색이 있는 클릭 가능한 항
  init(p), step(st,p,dt), draw(ctx,st,p,ui), readouts(st,p),
  graphs, sample, notes, presets
});
```

그래프는 기본이 시간축이며, `window: 8`을 주면 최근 8초만 흐르듯 보여 주고, `xKey: 'F'`를 주면 시간 대신 그 값을 가로축으로 씁니다(교정 곡선·특성 곡선용).

`draw()`의 `ui.hl`에 현재 강조 중인 기호 키가 들어옵니다. 이 값에 따라 해당 화살표/막대를 `hot: true`로 그리면 공식 ↔ 화면 연결이 완성됩니다.

**공통**
- 학습 흐름: 시뮬레이션마다 "예측해 보기 → 값 조정 → 확인" 퀴즈 카드
- 기초 ↔ 심화 <b>연결 고리 표시</b>(예: F=ma → 감쇠 자유진동으로 바로 이동하는 버튼)
- 모바일 터치 대응(현재는 좁은 화면에서 세로로 쌓이는 정도까지만 대응)
