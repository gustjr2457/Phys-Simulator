# 매일 이론 — 후보 목록

매일 자동 실행(`.claude/skills/daily-theory/SKILL.md`)이 이 목록의 **맨 위 `대기` 항목**부터 하나씩 만든다.
`tools/daily-check.js` 는 새 시뮬레이션의 id 가 여기 있고 `중요도:` · `근거:` 줄이 있어야 기준 1 을 통과시킨다.

- 범위: **물리학 또는 항공우주공학**에서 중요한 이론만 (사용자 기준 1). 화학·전기공학 응용은 넣지 않는다.
- 이미 있는 74종과 겹치면 안 된다 — 추가 전 `node tools/test-sims.js --list` 로 확인.
- `대기` 가 5개 아래로 떨어지면 자동 실행이 조사해서 근거와 함께 보충한다. 근거는 교육과정·표준 교재·전공 과목 등 확인 가능한 것만.
- 상태: `대기` · `완료 YYYY-MM-DD` · `보류 — 이유` (관문을 끝내 못 넘은 경우)

항목 형식
```
### `id` — 제목
- 상태: 대기
- 위치: mode / 소분류(category)
- 중요도: ★★★ (★ 셋 = 해당 분야 필수)
- 근거: 어느 교육과정·교재·전공 과목의 핵심 내용인가
- 핵심 공식:
- 중학생 연결고리: 일상에서 이미 겪어 본 무엇과 이어지는가
- 물리 검증: tests/physics/<id>.js 에서 독립 계산으로 비교할 값 (3개 이상)
```

### `b-projectile` — 포물선 운동
- 상태: 완료 2026-11-13
- 위치: basic / 역학과 에너지
- 중요도: ★★★
- 근거: 고등학교 물리학Ⅰ(힘과 운동) · 물리학Ⅱ(평면 운동)의 핵심 단원. 대학 일반물리 2차원 운동. 탄도·발사 궤적의 출발점(항공우주).
- 핵심 공식: x = v₀cosθ·t, y = v₀sinθ·t − ½gt², 사거리 R = v₀²sin2θ/g, 최고 높이 H = v₀²sin²θ/(2g)
- 중학생 연결고리: 공을 비스듬히 던지면 왜 45°에서 가장 멀리 가는가 — 가로는 그대로, 세로만 중력이 당긴다
- 물리 검증: 사거리(θ=30°, 45°), 최고 높이, 비행 시간 2v₀sinθ/g

### `aero-atmosphere` — 표준 대기: 높이 올라가면 공기는 어떻게 변하나
- 상태: 완료 2026-11-14
- 위치: aero / 비행역학
- 중요도: ★★★
- 근거: ICAO 국제 표준 대기(ISA)는 항공기 성능·고도계·엔진 정격의 기준. 항공우주공학 비행역학·공기역학 첫 단원.
- 핵심 공식: 대류권 T = T₀ − Lh (L = 6.5 K/km), p = p₀(T/T₀)^(g/(LR)), ρ = p/(RT); 성층권(11~20 km) 등온 p ∝ e^(−gh/(RT))
- 중학생 연결고리: 산에 오르면 귀가 먹먹하고 과자 봉지가 부푼다 — 위로 갈수록 머리 위 공기가 적어 누르는 힘이 줄어든다
- 물리 검증: 해면 p₀ = 101325 Pa · ρ₀ = 1.225; 11 km 에서 T = 216.65 K · p ≈ 22632 Pa; 5 km 밀도 ≈ 0.736 kg/m³

### `g-pendulum` — 단진자와 주기
- 상태: 완료 2026-11-15
- 위치: general / 역학과 진동
- 중요도: ★★★
- 근거: 물리학Ⅱ 단진동 단원, 일반물리 진동. 갈릴레이의 등시성 → 시계의 원리. 소각 근사의 한계까지 보여 줄 수 있다.
- 핵심 공식: T = 2π√(L/g) (작은 각), 큰 각 보정 T ≈ 2π√(L/g)(1 + θ₀²/16)
- 중학생 연결고리: 그네는 세게 밀든 살살 밀든 한 번 왕복하는 시간이 거의 같다 — 줄 길이만 바꾼다
- 물리 검증: L=1 m 주기 2.006 s; L 네 배면 주기 두 배; 달(g=1.62)에서 주기; 큰 진폭 보정 방향

### `aero-turn` — 선회 비행과 하중 배수
- 상태: 완료 2026-11-16
- 위치: aero / 비행역학
- 중요도: ★★★
- 근거: 비행역학 기동 성능(선회 반경·선회율·하중 배수 n = 1/cos φ). 조종사 교육의 기본, 구조 설계 하중의 출발점.
- 핵심 공식: n = 1/cos φ, R = V²/(g·tan φ), ω = g·tan φ / V, 실속 속도는 √n 배로 증가
- 중학생 연결고리: 롤러코스터가 기울어 돌 때 몸이 의자에 꽉 눌린다 — 비행기도 기울여 돌면 날개가 더 큰 힘을 받는다
- 물리 검증: 60° 경사에서 n = 2; V=100 m/s, φ=30° 의 선회 반경; 실속 속도 배율 √n

### `g-circular` — 등속 원운동과 구심력
- 상태: 대기
- 위치: general / 역학과 진동
- 중요도: ★★★
- 근거: 물리학Ⅱ 원운동, 일반물리. 인공위성·선회 비행·원심분리기를 이해하는 바탕.
- 핵심 공식: a = v²/r = ω²r, F = mv²/r, T = 2πr/v
- 중학생 연결고리: 줄에 매단 공을 돌리다 놓으면 원의 바깥이 아니라 그 순간의 접선 방향으로 날아간다
- 물리 검증: 구심 가속도 v²/r; 주기 2πr/v; 줄을 놓은 뒤 직선 운동 방향

### `space-kepler3` — 케플러 제3법칙: 멀수록 느리게, 오래 돈다
- 상태: 대기
- 위치: astro / 우주의 크기 재기
- 중요도: ★★★
- 근거: 물리학Ⅰ 중력 단원, 일반물리 만유인력. 궤도역학의 기본 관계(T² ∝ a³) — 행성 질량 측정에 쓰인다.
- 핵심 공식: T² = 4π²a³/(GM)
- 중학생 연결고리: 태양계 행성은 바깥쪽일수록 한 바퀴 도는 데 훨씬 오래 걸린다 — 지구 1년, 화성 1.88년, 목성 11.9년
- 물리 검증: a=1 AU → T=1 년; a=5.2 AU → 11.86 년; a 를 4배 하면 T 는 8배

### `g-buoyancy` — 부력과 아르키메데스 원리
- 상태: 대기
- 위치: general / 유체역학
- 중요도: ★★★
- 근거: 중학교 과학·물리학Ⅰ 유체, 일반물리 유체 정역학. 배·잠수함·열기구·기상 관측 풍선의 원리.
- 핵심 공식: F_B = ρ_유체·g·V_잠긴, 뜨는 조건 ρ_물체 < ρ_유체, 잠기는 비율 = ρ_물체/ρ_유체
- 중학생 연결고리: 쇳덩이는 가라앉는데 쇠로 만든 배는 뜬다 — 밀어낸 물의 무게만큼 위로 밀린다
- 물리 검증: 나무(ρ=600)가 물에 60 % 잠김; 부력 = 밀어낸 물의 무게; 바닷물(1025)에서 더 얕게 잠김

### `aero-thrust` — 제트 엔진의 추력
- 상태: 대기
- 위치: aero / 로켓 추진
- 중요도: ★★★
- 근거: 항공우주 추진공학 기본(운동량 정리로 본 추력). 뉴턴 제3법칙의 공학적 응용.
- 핵심 공식: F = ṁ(V_out − V_in) (+ 압력항 생략), 추진 효율 η_p = 2/(1 + V_out/V_in)
- 중학생 연결고리: 풍선을 불었다 놓으면 바람을 뒤로 뿜으며 앞으로 날아간다 — 뒤로 던진 공기의 양×속도만큼 앞으로 밀린다
- 물리 검증: ṁ=100 kg/s, ΔV=300 m/s → 30 kN; 추진 효율 공식; 비행 속도가 오르면 같은 배기 속도에서 추력 감소

### `g-idealgas` — 기체 분자 운동과 이상기체
- 상태: 대기
- 위치: general / 열과 통계
- 중요도: ★★★
- 근거: 물리학Ⅱ 열역학, 일반물리 기체 분자 운동론. 압력의 미시적 정체 — 대기·엔진·우주선 환경 제어의 바탕.
- 핵심 공식: PV = NkT, ½m⟨v²⟩ = (3/2)kT (2차원 시뮬레이션이면 ½m⟨v²⟩ = kT)
- 중학생 연결고리: 여름에 자전거 타이어가 팽팽해진다 — 분자가 빨라져 벽을 더 세게, 더 자주 친다
- 물리 검증: 벽 충돌로 잰 압력 × 넓이 = NkT (통계 오차 범위); 온도 두 배 → 압력 두 배; 부피 반 → 압력 두 배

### `aero-stability` — 세로 안정성: 무게중심과 공력중심
- 상태: 대기
- 위치: aero / 비행역학
- 중요도: ★★★
- 근거: 비행역학 정적 안정성(무게중심이 중립점보다 앞에 있어야 한다, 정적 여유). 항공기 설계·적재의 핵심 제약.
- 핵심 공식: 정적 여유 = (x_np − x_cg)/c, 피칭 모멘트 기울기 dCm/dα < 0 이면 안정
- 중학생 연결고리: 종이비행기 앞쪽에 클립을 끼우면 안정적으로 날고, 뒤쪽에 끼우면 곤두박질친다
- 물리 검증: x_cg < x_np 일 때 교란이 줄어든다(진폭 감소); 경계(x_cg = x_np)에서 복원 모멘트 0; 정적 여유 계산

### `g-torque` — 돌림힘과 지레
- 상태: 대기
- 위치: basic / 역학과 에너지
- 중요도: ★★★
- 근거: 중학교 과학·물리학Ⅰ 힘의 평형, 일반물리 강체 평형. 구조물·조종면·관절의 기본.
- 핵심 공식: τ = r F sinθ, 평형 Στ = 0 (F₁d₁ = F₂d₂)
- 중학생 연결고리: 시소에서 무거운 사람이 가운데로 앉으면 가벼운 사람과 균형이 맞는다
- 물리 검증: F₁d₁ = F₂d₂ 균형점; 힘이 비스듬하면 sinθ 배; 평형이 아니면 회전 방향

### `q-halflife` — 방사성 붕괴와 반감기
- 상태: 대기
- 위치: quantum / 원자핵과 방사선 (새 소분류 — 양자역학 과정 맨 끝에 둔다)
- 중요도: ★★★
- 근거: 물리학Ⅰ 핵반응·방사선 단원, 현대물리. 탄소 연대 측정, 우주선(RTG) 전원.
- 핵심 공식: N = N₀(1/2)^(t/T½), 붕괴 상수 λ = ln2/T½
- 중학생 연결고리: 동전 100개를 던져 앞면만 빼면 매번 대략 절반씩 남는다 — 하나하나는 우연, 전체는 규칙
- 물리 검증: 기대값 N₀/2 at T½ (큰 N 에서 통계 범위); λ = ln2/T½; 두 반감기 뒤 1/4

### `space-attitude` — 반작용 휠과 자세 제어
- 상태: 대기
- 위치: aero / 궤도역학
- 중요도: ★★☆
- 근거: 우주선 자세 제어의 기본(각운동량 보존, 반작용 휠). 허블·JWST 가 이것으로 방향을 바꾼다. 일반물리 각운동량 보존의 응용.
- 핵심 공식: I_sat·ω_sat + I_wheel·ω_wheel = 0 (처음에 정지)
- 중학생 연결고리: 회전 의자에 앉아 바퀴를 돌리면 의자가 반대로 돈다
- 물리 검증: 각운동량 합 = 0 유지; ω_sat = −(I_w/I_s)ω_w; 휠을 멈추면 위성도 멈춤

### `g-friction` — 마찰력과 빗면
- 상태: 대기
- 위치: basic / 역학과 에너지
- 중요도: ★★★
- 근거: 물리학Ⅰ 힘과 운동, 일반물리 뉴턴 법칙의 응용. 착륙 활주·제동 거리의 기본.
- 핵심 공식: f = μN, 빗면 a = g(sinθ − μcosθ), 미끄러지기 시작하는 각 tanθ = μ_s
- 중학생 연결고리: 미끄럼틀이 가파를수록 빨라지고, 고무 매트 위에서는 잘 안 미끄러진다
- 물리 검증: 빗면 가속도; 정지 조건 tanθ ≤ μ; 수평에서 제동 거리 v²/(2μg)

### `aero-reynolds` — 레이놀즈 수와 경계층
- 상태: 대기
- 위치: aero / 비행역학
- 중요도: ★★☆
- 근거: 공기역학·유체역학 핵심 무차원수. 층류/난류 천이, 풍동 시험의 상사 법칙.
- 핵심 공식: Re = ρVL/μ, 평판 층류 경계층 두께 δ ≈ 5x/√Re_x
- 중학생 연결고리: 꿀은 천천히 매끄럽게, 수돗물을 세게 틀면 거칠게 소용돌이친다
- 물리 검증: 공기(해면) V=50 m/s, L=1 m 의 Re; δ 공식; Re ≈ 5×10⁵ 부근 천이

### `exp-michelson` — 마이컬슨-몰리 실험 (1887)
- 상태: 완료 2026-11-22
- 위치: exp / 빛의 정체를 밝히다
- 중요도: ★★☆
- 근거: 특수 상대성이론으로 가는 결정적 실험(에테르 부정). 간섭계는 LIGO 중력파 검출의 원리.
- 핵심 공식: 광로차 → 간섭 무늬 이동 ΔN = 2LΔ/λ (에테르 가설의 예측 vs 관측 0)
- 중학생 연결고리: 강물을 따라 갔다 오는 배와 강을 가로질러 갔다 오는 배는 걸리는 시간이 다르다 — 빛도 그래야 했는데, 아니었다
- 물리 검증: 에테르 가설 예측 무늬 이동량(L=11 m, v=30 km/s, λ=500 nm → 약 0.4); 팔 길이 같으면 정렬; 관측 0

### `space-lagrange` — 라그랑주 점
- 상태: 대기
- 위치: aero / 궤도역학
- 중요도: ★★☆
- 근거: 제한 삼체문제의 평형점. JWST(L2)·SOHO(L1) 의 위치. 궤도역학 고급 주제.
- 핵심 공식: 회전 좌표계 유효 퍼텐셜 Φ = −GM₁/r₁ − GM₂/r₂ − ½ω²r²; L1·L2 ≈ R(μ/3)^(1/3)
- 중학생 연결고리: 지구와 태양이 당기는 힘과 같이 도는 효과가 딱 맞아 떨어져 "같이 따라 도는" 자리가 다섯 군데 있다
- 물리 검증: 지구-태양 L2 거리 ≈ 1.5×10⁶ km; L4·L5 는 정삼각형 꼭짓점; 평형점에서 유효 힘 0

### `g-pressure` — 유체 압력과 파스칼 원리
- 상태: 대기
- 위치: general / 유체역학
- 중요도: ★★★
